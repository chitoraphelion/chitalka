Горячие клавиши

Выделить мышью → C или Enterкомментировать выделенное
1…5 после выделениякомментарий с категорией: опечатка, переписать, факт, вопрос, мысль
N (с выделением или без)личная заметка: только для вас, агенту не отправляется
Ctrl+Enterсохранить комментарий или заметку
Escсвернуть редактор (черновик сохранится)
J / Kследующий / предыдущий комментарий (на вкладке «Мои заметки» — заметка)
/поиск по статье (Enter — следующее совпадение)
Gперейти на страницу
Ctrl или Cmd + = / − / 0крупнее / мельче / по ширине
+ − Wто же без Ctrl
[ ] Hскрыть или показать оглавление, комментарии, шапку
Fрежим чтения: скрыть всё и вернуть как было
Rзагрузить пересобранную статью
Клик по ссылке, Alt+←перейти (литература, формула, раздел) и вернуться
Навести на ссылкупредпросмотр места, куда она ведёт
E, «✎ файл:строка» на карточкеоткрыть место в исходнике в nvim
D / Iтема: тёплая светлая ↔ тёмная / тёмные страницы

Клавиши работают в любой раскладке. Закрыть — Esc или клик мимо.
