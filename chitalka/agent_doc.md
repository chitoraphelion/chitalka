# Комментарии автора из читалки: как с ними работать

Автор читает PDF или Markdown с формулами в читалке (`chitalka`), выделяет фрагменты и пишет, что исправить.
Комментарии лежат в `{STORE}` рядом с этим файлом. Твоя задача — исправить исходники,
проверить результат и ответить в комментарии.

## Порядок работы

1. `chitalka list` — открытые комментарии, ждущие ответа (запускать из корня проекта,
   где хранятся комментарии). `chitalka show ID` — один комментарий целиком.
2. Найди место: поле `source` = `файл:строка`.
   - `(synctex)` — точная строка по координатам выделения;
   - `(markdown)` — диапазон строк блока `.md` (абзац, формула, список); уточни фрагмент по `quote`.
   - `(words)` — найдено поиском по словам, может промахнуться: проверь по `quote`.
   - `source` пуст — ищи по `quote` (это текст из PDF, формулы в нём в виде символов).
3. Исправь исходник `.tex` или `.md` по полю `comment`; `suggestion` — дословная замена, если автор её дал.
   `category`: typo — опечатка, rewrite — переписать, fact — проверить факт,
   ask — вопрос (ответить, текст можно не менять), idea — мысль.
4. Для Markdown сохрани файл: читалка сама обновится, latexmk не нужен.
   Формулы в `quote` записаны TeX-исходником; поддерживаются `$…$`, `$$…$$`, `\(…\)`, `\[…\]` через KaTeX.
   Для PDF пересобери PDF (`latexmk -synctex=1 …`, PDF — `./main.pdf` или `./build/main.pdf`):
   читалка сама предложит автору обновить статью.
   Если читалка запущена с `--watch` (рядом есть свежий `latexmk.log`), latexmk уже следит
   за файлами и пересоберёт сам — не запускай второй latexmk, ошибки смотри в `latexmk.log`.
5. Ответь и закрой:
   - `chitalka reply ID "что сделано" --done` — исправлено;
   - `chitalka reply ID "вопрос или пояснение"` — нужно решение автора (комментарий остаётся открытым);
   - `chitalka done ID ... -m "текст"` — закрыть несколько сразу.

## Правила

- В проекте может быть несколько документов: сначала проверь `document` и `source.file`.
- Не удаляй комментарии и не правь поля автора (`quote`, `comment`, `suggestion`, `thread` с `who: author`).
- Если автор дописал уточнение (`who: author` после твоего ответа), комментарий снова открыт — продолжи.
- Отвечай на языке автора, коротко: что изменено и где (`файл:строка`).
- Файл можно читать напрямую (`{STORE}`, JSON-массив), но меняй его только через `chitalka`:
  команды берут блокировку, и правка не потеряется, если читалка открыта.

## Поля комментария

`id`, `created`, `status` (open|done), `category`, `page`/`pageEnd` (страницы PDF / разделы Markdown с 1),
`document` (путь документа от корня проекта), `chapter`, `quote`, `comment`, `suggestion`, `source` {file, line, lineEnd?, how},
`anchor` (координаты выделения в PDF), `reply` и `thread` [{who: author|ai, text, at}] — переписка.
